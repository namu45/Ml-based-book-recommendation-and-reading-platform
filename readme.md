# 📚 Book Recommendation and Reading Platform

A machine learning–based book recommendation and reading platform built using Django.  
It provides personalized book recommendations using content-based and collaborative filtering, along with features like rating, review, and reading history tracking.

---

## 🚀 Features
- Book recommendations using ML  
- Content-based and collaborative filtering  
- Rating and review system  
- Reading history tracking  
- Bookmark favorite books  
- Sentiment analysis on reviews  

---

## 🛠️ Technologies Used
- Python, Django  
- HTML, CSS, JavaScript  
- Machine Learning & NLP libraries  
- Dataset: Project Gutenberg & Book-Crossing  

---
